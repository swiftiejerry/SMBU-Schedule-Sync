# 📅 SMBU Schedule Sync

**Превратите расписание из учебной системы SMBU в календарь вашего телефона — одним нажатием.**

Введите данные CAS → сервер сам загружает расписание любого семестра → скачайте файл `.ics` и импортируйте его в календарь iOS / Android / компьютера.

## 🚀 Возможности

- **Действительно одно нажатие** — вход CAS и загрузка данных из системы «Цянчжи» полностью выполняются на сервере; на телефоне ничего настраивать не нужно
- **История всех семестров** — доступно расписание любого семестра с момента поступления
- **Три языка интерфейса** — 简体中文 / English / Русский
- **Тёмная тема** — автоматически следует за системой, есть ручное переключение
- **`.ics` по стандарту RFC 5545** — часовой пояс Asia/Shanghai, напоминания перед занятием (выкл/10/15/20/30 мин), точное сопоставление недель и учебных пар
- **Ваш пароль остаётся вашим** — учётные данные живут только в сессии в оперативной памяти: ничего не пишется на диск, не логируется, никуда не отправляется и удаляется при выходе

## 🏗️ Как это работает

```
Браузер ──HTTPS──▶ FastAPI ──httpx──▶ authserver.smbu.edu.cn (CAS)
                              └─httpx──▶ jw.smbu.edu.cn/jwapp  (REST «Цянчжи»)
```

1. Фронтенд отправляет учётные данные на `/api/auth/login` (пароль используется один раз в памяти и сразу удаляется)
2. Бэкенд выполняет вход в CAS (имя пользователя + пароль, зашифрованный AES-CBC) и получает cookie-сессию jwapp
3. Загружаются список семестров, даты недель, время пар и расписание — всё приводится к единой модели
4. Генерируется `.ics`: одно событие VEVENT на каждую еженедельную пару, с часовым поясом и напоминаниями

> Вне кампуса бэкенд автоматически идёт через туннель WebVPN (Srun + рукопожатие headless-браузера) — подробности в [WEBVPN.md](WEBVPN.md).

## 📦 Быстрый старт (Docker)

```bash
docker build -f deploy/Dockerfile -t smbu-calendar:latest .
docker run -d --name smbu-app -p 8771:8770 --restart unless-stopped \
  smbu-calendar:latest
# откройте http://localhost:8771
```

Полное развёртывание (TLS / ограничение частоты запросов через nginx / режим доступа WebVPN / офлайн-нагрузочное тестирование с мок-сервером) описано в [deploy/README.md](deploy/README.md).

### Локальная разработка

```bash
# бэкенд
cd backend && pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8770

# фронтенд
cd frontend && npm install && npm run dev   # http://localhost:5173
```

Переменные окружения (префикс `SMBU_`) описаны в [backend/app/config.py](backend/app/config.py).

## 🔒 Безопасность и приватность

- Пароль появляется ровно один раз — в памяти запроса на вход — и сразу исчезает; базы данных нет, сессии живут в памяти и автоматически истекают
- Глобальный ограничитель параллельных запросов к учебной системе плюс скользящие лимиты по IP/студенту: при всплесках трафика возвращается корректный 429 вместо того, чтобы укладывать учебную систему
- Отчёт о нагрузочном тестировании: [docs/STRESS_REPORT.md](docs/STRESS_REPORT.md)

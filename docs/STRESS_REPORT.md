## 压测中发现并已修复的生产 Bug

**位置**：`backend/app/main.py` 登录处理器（原第 195 行）

**问题**：残留一行 `await limiter.check(f"student:{student_id}", 1)  # seed the bucket`
（limit=1，且不在 `except RateLimited` 保护内）。同一学生 **60s 内重复登录**会抛 `RateLimited`，
冒泡到全局 `except Exception` → **返回 500 INTERNAL**（本应正常登录）。

**修复**：删除该行。per-student 限流本就在数据接口（schedule/terms/export）按 `student:{id}`
正确施加，登录本身已有独立的登录限流（line 149）。

**验证**：同一学生连续 3 次登录均返回 200（修复前第 2 次起即 500）。
